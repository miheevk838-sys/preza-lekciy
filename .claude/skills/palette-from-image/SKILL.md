# Палитра из картинки → токены деки

## Шаги
1. Посмотреть картинку из `palettes/`. Если на ней есть подписи HEX/RGB — взять их дословно.
   Если подписей нет — определить 4–6 доминирующих цветов «на глаз» по картинке.
2. Разложить цвета по ролям (от тёмного фона к светлому тексту и акцентам):
   - **фон** (самый тёмный/глубокий) → `--void`, чуть светлее → `--void2`, ещё → `--panel`.
   - **светлый текст и плашки** (самый светлый) → `--wheat`; тёмный текст на плашке → `--ink`.
   - **главный акцент** (самый «звучный» тёплый/яркий) → `--terra`, его тёмный вариант → `--terra-d`.
   - **вторичный акцент** (контрастный к главному) → `--cyan` (светлый) и `--teal` (тёмная карточка).
   - **глубокая карточка** → `--espresso`; **приглушённый текст** → `--tan` и `--tan-d`.
   - линии: `--hair` = rgba светлого текста .15, `--hair-strong` = .30.
3. Проверить контраст: светлый текст на тёмном фоне читаем; акцент заметен на фоне. При нужде слегка осветлить/затемнить.
4. Выдать готовый блок `:root { … }`, объект `PAL = { … }` для canvas и градиент `.field`.

## Шаблон вывода
```css
:root{
  --void:#__; --void2:#__; --panel:#__;
  --wheat:#__; --ink:#__;
  --terra:#__; --terra-d:#__;     /* главный акцент */
  --teal:#__; --cyan:#__;         /* вторичный акцент */
  --espresso:#__;
  --tan:#__; --tan-d:#__;
  --hair:rgba(R,G,B,.15); --hair-strong:rgba(R,G,B,.30);
}
```
```js
const PAL = {
  ink:'#__', grid:'rgba(R,G,B,.08)', axis:'rgba(R,G,B,.30)',
  terra:'#__', cyan:'#__', teal:'#__', tan:'#__', tand:'#__', wheat:'#__'
};
```
`.field` — три радиальных градиента из акцента, вторичного и фона.

## Правило
Имена токенов НЕ меняются между главами — меняются только значения. Так перекраска не ломает движок.
